Project workspaces

Projects, addresses and settings. Changes are kept when you click Save.

Projects and their addresses

A tab that opens one of these addresses moves to that project. Only the exact address matches: example.com does not match www.example.com; *.example.com matches example.com and every address that ends with it. Local addresses work too, like localhost:3000. A tab you put in a group yourself is never moved. Drag a project by its handle to change the order.

Behaviour

The project row is always one key away: set a key for "Open the project row" below.

The narrow project window is the side panel's list in a window of its own, attached to the side of its Brave window. Each Brave window has its own: the toolbar button opens it, and closes it again. It can be narrower than the side panel: it starts at 300 px, and when you drag its edge it keeps the new width. Move, resize, maximize or minimize Brave, and the list goes along. To go back, choose the side panel here again: the windows close and Brave gets its whole screen back.

Side panel: left or right

Brave shows the side panel together with its sidebar, on the right or on the left.

To move it: Brave Settings > Appearance > Sidebar > Show on the left (or on the right). You can drag its inner edge, but not below 400 px: that minimum is built into Brave, and no setting or extension can lower it.

A narrow project list: Brave's vertical tabs

For a much narrower list, turn on Brave's vertical tabs: Brave Settings > Appearance > Tabs > Use vertical tabs. With this extension, each project is then one row in that strip, and only the open project shows its tabs. Drag the strip's edge to make it as narrow as you like (110 px works). Click a project row to open it; the others fold.

In the same place: Show on the right moves the strip to the right, and Auto expand on hover when minimized shrinks it to a thin bar that widens when you point at it. The side panel is then only needed to rename or reorder projects.

Keyboard shortcuts

Brave lets an extension suggest only four keys, so Project 1 to Project 4 start on Alt+1 to Alt+4. You can set the others yourself.

    Privacy

    This extension never connects to the internet. It sends nothing anywhere, has no analytics and runs no code from outside. It reads tab addresses only for the rules and the warning above, on this computer. Your projects, addresses and settings stay in this Brave profile.

    • tabs: see tab addresses, for the rules and the warning.
    • tabGroups: open, fold and move tab groups.
    • storage: remember projects, addresses and settings.
    • sidePanel: show the project list at the side.
